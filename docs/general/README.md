# Task Group documentation

This directory is the durable context for developers and AI agents. Read the documents before proposing code or changing architecture.

## Reading order

1. `general/product-requirements.md`
2. `general/business-rules.md`
3. `general/use-cases.md`
4. `general/system-flow.md`
5. `general/folder-structure.md`
6. `backend/architecture.md`, then `backend/data-model.md`
7. `backend/api-contract.md` and `backend/security.md`
8. `frontend/frontend-architecture.md`
9. `general/development-roadmap.md` and `backend/deployment.md`

## Change rule

Before adding a feature, update the requirements, affected business rules, data model, API contract, frontend behaviour, and tests. The simplest maintainable solution wins; do not introduce a new platform or service without a concrete requirement.
